# gurupras/homebrew-tap

Homebrew formulae for my projects.

```sh
brew tap gurupras/tap
brew install gurupras/tap/<formula>
```

| Formula | Project |
|---|---|
| `agent-keepalive` | [agent-keepalive-manager](https://github.com/gurupras/agent-keepalive-manager) |

Formulae are published by each project's release workflow; don't edit them by hand.
